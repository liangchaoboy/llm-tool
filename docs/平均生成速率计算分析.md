## 二、已修复的问题 ✅

### 2.1 ✅ 问题1: 使用估算的测试时间 - 已修复

**原问题位置**: `performance.go:191`

**原问题描述**:
- `testDuration` 使用固定公式估算：`并发数 × 每并发请求数 × 100毫秒`
- 这不是实际的测试运行时间
- 导致 `AvgGenerationRate` 计算不准确

**修复方案**:
- 在 `RunPerformanceTest` 开始时记录 `testStartTime := time.Now()`
- 测试结束后计算 `actualTestDuration := time.Since(testStartTime)`
- 使用 `actualTestDuration.Seconds()` 计算所有速率指标

**修复位置**: `performance.go:93, 192, 209`
```go
testStartTime := time.Now()  // 记录开始时间
// ... 测试代码 ...
actualTestDuration := time.Since(testStartTime)  // 计算实际耗时
testDurationSeconds := actualTestDuration.Seconds()
```

### 2.2 ✅ 问题2: Token数计算方式不准确 - 已修复

**原问题位置**: `performance.go:142-146`

**原问题描述**:
```go
outputTokens = len([]rune(resp.Choices[0].Message.Content))
```
- 使用字符数（rune数）来估算token数
- 中文字符、英文单词、标点符号的token数差异很大

**修复方案**:
- 优先使用API返回的真实token数：`resp.Usage.CompletionTokens`
- 如果API没有返回token数，才使用字符数作为降级方案
- 同时修复了输入token数的计算，使用 `resp.Usage.PromptTokens`

**修复位置**: `performance.go:145-168`
```go
// 优先使用API返回的真实输出token数
outputTokens := 0
if resp.Usage.CompletionTokens > 0 {
    outputTokens = resp.Usage.CompletionTokens
} else if len(resp.Choices) > 0 {
    // 降级方案：如果API没有返回token数，使用字符数估算
    outputTokens = len([]rune(resp.Choices[0].Message.Content))
}

// 同样修复输入token数
inputTokens := 0
if resp.Usage.PromptTokens > 0 {
    inputTokens = resp.Usage.PromptTokens
} else {
    inputTokens = len([]rune(testCase.Prompt))
}
```

### 2.3 ✅ 问题3: AvgGenerationRate 与 OutputTPS 重复 - 已明确

**结论**: 这两个指标的计算公式完全相同，都是"输出Token/秒"。代码中已添加注释说明它们的一致性（第225行）。

## 四、修复后的计算流程 ✅

```
1. 记录测试开始时间 (testStartTime) ✅
2. 并发执行请求
3. 对每个响应：
   - 优先使用 resp.Usage.CompletionTokens 获取真实输出token数 ✅
   - 如果API未返回，使用字符数作为降级方案
   - 计算该请求的生成速率：requestGenerationRate = outputTokens / requestLatency.Seconds()
   - 累计到 totalGenerationRateSum（使用mutex保护并发访问）
   - 累计到 totalOutputTokens
4. 测试结束，计算实际测试时间 (actualTestDuration) ✅
5. 使用实际测试时间计算所有速率指标 ✅
   - AvgGenerationRate = totalGenerationRateSum / successfulRequestCount（每个请求的平均值）✅
   - OutputTPS = totalOutputTokens / actualTestDuration.Seconds()（整体速率）
   - TPS = totalTokens / actualTestDuration.Seconds()
   - RPS = successfulRequests / actualTestDuration.Seconds()
6. main.go 中显示测试耗时，所有指标已在 performance.go 中正确计算 ✅
```

### 4.1 AvgGenerationRate 与 OutputTPS 的区别

- **AvgGenerationRate**: 每个请求的平均生成速率
  - 计算方式：对每个请求计算 `输出token数 / 该请求耗时`，然后求平均
  - 反映：单个请求的平均生成速度
  
- **OutputTPS**: 整体输出token速率
  - 计算方式：`总输出token数 / 总测试时间`
  - 反映：整个测试期间的平均输出速率（考虑并发）
